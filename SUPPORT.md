# Support Information 🛠️ (URTC-COMMON)

Thank you for using URTC-COMMON! Here is how you can get help:

## 📺 Video Tutorials & Demos
The official YouTube channel covers the ecosystem's tools:
[youtube.com/@electrohobby3d](https://youtube.com/@electrohobby3d)

## ✉️ Direct Technical Inquiries
For questions about the protocol, the specification format or how a repository can adopt it:
Email: `electrohobby3d@gmail.com`

## 🐛 Bug Reports
If you found an identifier, a layout or a limit in `spec/can_protocol.json` that does not match what the firmware or a tool does, or a defect in the generators or the package, please open a **GitHub Issue** in this repository and name the identifier.
*Please search existing issues before opening a new one.*

## ❌ What is NOT support?
- Questions about running a specific tool belong in that tool's own repository.
- Please do not use Issues for "How to" questions.
